## Before using a calculation

- Review the workbook or notebook instructions and confirm all input units.
- Check assumptions, design conditions, material properties, and applicable codes/standards for the project and jurisdiction.
- Independently verify important results using an approved method or a second calculation.
- Treat the files as reference/design aids, not as a substitute for project-specific engineering review or approval.

## Scope of this index

Descriptions above identify the subject suggested by each filename and folder. They do not certify the underlying formulas, assumptions, or results. Those need to be checked against the contents of each individual file before the calculation method is documented or used for design.
